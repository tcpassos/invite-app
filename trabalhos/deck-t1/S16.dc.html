Interfaces no arquivo de compose

Onde ficam a interface
provida e a requerida

services:
api:
image: node:22-alpine
ports:
- "3000:3000" # interface provida
environment:
DATABASE_URL: ... # interface requerida
depends_on: [db]
db:
image: postgres:16
//

A porta publicada mais o contrato HTTP é a interface provida, o pirulito da UML.

//

A variável de conexão mais a dependência declarada é a interface requerida, o soquete.

//

A porta da UML é literalmente a porta do container, com o mesmo desenho e o mesmo nome.

//

As imagens do arquivo são exemplo. A stack ainda não foi decidida e é assunto do ADR.

Dockerfile, imagem e container

Receita
Dockerfile

Arquivo de texto com a imagem base, as dependências e o comando de inicialização.

FROM node:22-alpine
COPY . /app
CMD ["node", "/app/api.js"]
Artefato
Imagem

Resultado do build. Pacote em camadas, imutável, publicado num registry.

$ docker build -t api:1.0 .
api:1.0  sha256:9f2c4e…
Execução
Container

Resultado do run. Processo criado a partir da imagem, com uma camada gravável própria.

$ docker run -p 3000:3000 api:1.0
PID 1  node /app/api.js
Um registry, como o Docker Hub, guarda e distribui as imagens. As imagens da demonstração vêm de lá prontas, sem build local.

# Sprint 3: projeto da solução e prototipação

## Objetivos da Sprint

- Consolidar a proposta arquitetural, definindo as tecnologias, os padrões de projeto e os mecanismos da implementação.
- Projetar a experiência do usuário e elaborar protótipos que validem a solução antes de implementar.
- Refinar a documentação arquitetural e detalhar os principais cenários de interação entre os componentes.
- Preparar a equipe para o início da implementação, reduzindo riscos técnicos.

## Questões Norteadoras

- Quais tecnologias, frameworks e ferramentas são mais adequados para a implementação?
- Quais padrões arquiteturais e padrões de projeto contribuem para a qualidade da solução?
- Como validar a experiência do usuário antes do desenvolvimento?
- Como documentar a arquitetura para apoiar a implementação e a evolução do sistema?
- Como os principais casos de uso são realizados pelos componentes da arquitetura?
- Como garantir que o projeto continua alinhado aos requisitos e aos atributos de qualidade das sprints anteriores?
